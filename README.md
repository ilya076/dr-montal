# Centre Mèdic la Garriga

Одностраничный сайт медицинского центра на React, Vite и Tailwind CSS.

## Быстрый запуск

1. Откройте терминал в папке проекта.
2. Один раз установите зависимости:

   ```bash
   npm install
   ```

3. Запустите сайт:

   ```bash
   npm start
   ```

Браузер откроется автоматически. Если этого не произошло, откройте
`http://localhost:5173/` вручную. Терминал должен оставаться открытым, пока вы
работаете с сайтом. Открытие `index.html` двойным щелчком не запускает Vite-
приложение и не является корректным способом просмотра.

## Проверка и production-сборка

```bash
npm run check
npm run preview
```

Production preview доступен по адресу `http://localhost:4173/`.

## Деплой

Каждый push в ветку `main` автоматически собирает и публикует сайт через
GitHub Actions. Пользовательский домен хранится в `CNAME`:
`dr-montal.is-a.dev`.

Перед первым деплоем в настройках GitHub-репозитория откройте
**Settings → Pages → Build and deployment** и выберите **GitHub Actions**.

## Если порт занят

Команда завершится с понятной ошибкой вместо незаметного перехода на другой
порт. Остановите предыдущий сервер сочетанием `Ctrl+C` в его терминале, затем
снова выполните `npm start`.
