# Centre Mèdic la Garriga

Одностраничный сайт медицинского центра на React, Vite и Tailwind CSS.

## Быстрый запуск

1. Откройте терминал в папке проекта.
2. Один раз установите зависимости:

   ```bash
   npm install
   ```

3. Запустите сайт:

   ```bash
   npm start
   ```

Браузер откроется автоматически. Если этого не произошло, откройте
`http://localhost:5173/` вручную. Терминал должен оставаться открытым, пока вы
работаете с сайтом. Открытие `index.html` двойным щелчком не запускает Vite-
приложение и не является корректным способом просмотра.

## Проверка и production-сборка

```bash
npm run check
npm run preview
```

Production preview доступен по адресу `http://localhost:4173/`.

## Умная запись через Google Calendar

Сайт показывает только реальные рабочие окна клиники: понедельник–четверг
07:30–13:00 и 16:00–19:30, пятница 09:00–13:00. Суббота и воскресенье
закрыты. Слоты имеют длительность 30 минут, доступны максимум на 60 дней
вперёд и требуют минимум 4 часа до начала.

Перед подтверждением Vercel Function повторно проверяет занятость Google
Calendar и создаёт событие с детерминированным ID. Поэтому один слот нельзя
занять дважды даже при одновременной отправке двух форм. События с отпусками,
праздниками или другими визитами в Google Calendar автоматически закрывают
соответствующее время на сайте.

Для подключения календаря `ilyauauaua2@gmail.com`:

1. В Google Cloud создайте отдельный service account и включите Google
   Calendar API.
2. Откройте настройки календаря `ilyauauaua2@gmail.com`, добавьте email
   service account в **Share with specific people** и дайте право
   **Make changes to events**.
3. Добавьте в Vercel для Production, Preview и Development переменные из
   `.env.example`: `GOOGLE_CALENDAR_ID`, `GOOGLE_SERVICE_ACCOUNT_EMAIL` и
   `GOOGLE_PRIVATE_KEY`.
4. Выполните новый deployment. Пароль Google-аккаунта сайту не нужен и не
   должен храниться в репозитории.

В форме намеренно отсутствует поле для симптомов и диагноза: через обычную
веб-форму собираются только контактные данные и выбранная категория услуги.

## Деплой

Каждый push в ветку `main` автоматически собирает и публикует сайт через
GitHub Actions. Пользовательский домен хранится в `CNAME`:
`dr-montal.is-a.dev`.

Перед первым деплоем в настройках GitHub-репозитория откройте
**Settings → Pages → Build and deployment** и выберите **GitHub Actions**.

## Если порт занят

Команда завершится с понятной ошибкой вместо незаметного перехода на другой
порт. Остановите предыдущий сервер сочетанием `Ctrl+C` в его терминале, затем
снова выполните `npm start`.
